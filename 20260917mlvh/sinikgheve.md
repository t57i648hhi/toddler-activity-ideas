# 逍遥家族全解析：功效差异与适用人群一目了然

> 更新时间：2026-09-17 (UTC+8)

逍遥散作为北宋《太平惠民和剂局方》中的经典名方，以疏肝健脾、调和气血著称。历经千年演变，其衍生出“逍遥家族”多款中成药，如逍遥丸、丹栀逍遥丸、加味逍遥丸等。这些药品虽同源，却因成分增减而功效各异。本文带您厘清区别，精准选择。 

**基础款：逍遥丸**

组方特点：逍遥散原方（柴胡、白芍、当归等）。 

核心功效：疏肝解郁、健脾养血。 

适用症状： 

- 情绪低落、易怒或抑郁  

- 胸胁胀满、食欲不振  

- 女性月经不调（如经前乳胀、经期紊乱）  

常见误区： 

逍遥丸并非女性专属，男性肝郁气滞（如压力大、消化不良）同样适用。  

**清热加强版：**

**丹栀逍遥丸vs加味逍遥丸**

**二者均在逍遥丸基础上加入牡丹皮、栀子，但细节有别：**

**一句话区分： **

- 丹栀逍遥丸：肝火旺，热象明显（如口苦、便秘）。 

- 加味逍遥丸：肝郁伴轻度上火（如睡眠差、食欲不振）。  

**活血化瘀款：红花逍遥片**

组方特点：逍遥散 + 红花（活血通经）。 

核心功效：疏肝理气 + 活血化瘀。 

适用症状： 

- 固定部位刺痛、皮肤易现瘀斑  

- 舌质暗紫或有瘀点  

- 经血暗红、血块多  

注意：孕妇禁用，女性经期慎用。  

**养血滋阴款：黑逍遥散**

组方特点：逍遥散 + 熟地黄（滋阴补血）。 

核心功效：疏肝健脾 + 补血调经。 

适用症状： 

- 面色萎黄、头晕乏力  

- 失眠健忘、经血量少色淡  

- 舌质淡白、舌苔薄白  

**使用须知：**

**避开误区，安全用药**

1. 饭后服用：含柴胡等成分，可能刺激胃肠道。 

2. 疗程控制：连服不超过半年，若一周无效需及时就医。 

3. 禁忌人群： 

- 孕妇：红花逍遥片禁用，其余慎用。

- 阴虚火旺或高血压患者：慎用含柴胡的药品。

- 中药易过敏人群避免服用。

4. 情绪调节：服药期间保持心情舒畅，避免郁怒。  

**速记口诀：**

> 逍遥古方疏肝郁，衍生家族功效异。

> 丹栀清热火力强，加味护胃更温和。

> 红花活血消瘀痛，黑逍补血面色红。

> 辨证选药是关键，肝脾调和百病通。
