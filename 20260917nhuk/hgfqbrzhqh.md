# 中药“和事佬”—甘草

> 更新时间：2026-09-17 (UTC+8)

在中药中，有一味被誉为和事佬的药材，几乎出现在每张处方中，那就是甘草。甘草具有润肺止咳、平肝息风、益气养阴等多种功效，在中医药中有着广泛的应用。今天就跟着小医一起了解中药届的和事老——甘草。

**甘  草**

【别名】蜜甘、蜜草、美草、灵通、国老、粉草。

【药性】甘、平，归心、肺、脾、胃经。

【功效】补脾益气，清热解毒，祛痰止咳，缓急止痛，调和诸药。

在中医上，甘草补脾益气，止咳润肺，缓急解毒，调和百药。临床应用分“生用”与“蜜炙”之别。生用主治咽喉肿痛，痛疽疮疡，胃肠道溃疡以及解药毒、食物中毒等；蜜炙主治脾胃功能减退，大便溏薄，乏力发热以及咳嗽、心悸等。甘草主要的应用有以下几种：

**1.心气不足、心律失常：**

甘草能补益心气、益气复脉，主要用于心气不足引起的心律失常、心脏早搏、心悸、心慌等，气血两虚者宜搭配人参、阿胶、生地黄等同用。

**2.脾气虚证：**

甘味药入脾，所以甘草最显而易见的作用就是补脾气，因其作用缓和，宜作为辅助药，配合人参、白术、黄芪等补脾益气药使用，以增强补其效果，治疗脾气虚弱证。

**3.咳喘：**

甘草能止咳，兼能祛痰，还略有平喘作用，单用有效，也可随证配伍用于寒热虚实多种咳喘，有痰无痰均宜。

**4.脘腹、四肢挛急疼痛：**

甘草能缓急止痛，对脾虚肝旺引起的脘腹挛急作痛或阴血不足导致的四肢挛急作痛，常与白芍同用。

**5.热毒疮疡、咽喉肿痛：**

生甘草清热解毒效果好，用治热毒疮疡及咽喉肿痛，可单用，可也与连翘、金银花、板蓝根、桔梗等清热解毒药配伍使用。

**6.调和药性：**

甘草在中药方中发挥调和药性的作用，一方面可降低有毒性药物的毒烈之性，另一方面可缓解药物对肠胃刺激引起的腹痛，且甜味浓郁，可减轻药物的苦味。

****

**鉴别甘草要点有四：**

- 
一是根圆柱形，红棕色或灰棕色；

- 
二是具纵沟皱及皮孔；

- 
三是质坚实，断面黄白色，形成层环纹明显；

- 
四是气微、具特殊甜味。

而类似品光果甘草则皮孔细而不明显，质坚实，断面裂隙较少，味甜；胀果甘草则根及根茎粗壮，灰棕色或褐色，质坚硬、少粉性，味甜或带苦。至于黄甘草、粗毛甘草则根条较细，甜味略差；刺果甘草、苦甘草则味苦，可供区别。

另外还需要注意的是，久服大剂量甘草，可引起浮肿。怀孕期间以及哺乳期间的女性，以及具有性功能障碍的男性最好不要服用甘草。日本研究认为久服甘草每日不宜超过5克。
