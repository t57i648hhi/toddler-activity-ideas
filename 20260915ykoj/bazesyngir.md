# 试管婴儿术前调理之番茄豆腐汤【广州试管】

> 更新时间：2026-09-15 (UTC+8)

对于准备进行试管婴儿的夫妇来说，术前的身体调理至关重要。今天，我们为大家带来一道营养丰富、美味可口的番茄豆腐汤，帮助大家在备孕的道路上更好地调理身体。

 

**一、食材准备 **

1. 番茄两个：番茄富含维生素 C、维生素 E、胡萝卜素、番茄红素等营养成分，具有抗氧化、防癌、美容养颜等功效。 

2. 豆腐一块：豆腐富含蛋白质、钙、磷、铁等营养成分，具有清热解毒、生津润燥、和中益气等功效。 

3. 鸡蛋一个：鸡蛋富含蛋白质、脂肪、维生素和矿物质等营养成分，具有滋阴润燥、养血安胎等功效。 

4. 葱姜蒜适量、盐、生抽、香油、食用油适量。 

**二、制作步骤** 

1. 番茄洗净，顶部划十字，放入开水中烫一下，去皮后切成小块。 

2. 豆腐切成小块，放入开水中焯水，去除豆腥味。

3. 鸡蛋打入碗中，搅拌均匀备用。 

4. 锅中加入适量食用油，烧热后放入葱姜蒜爆香。 

5. 加入番茄块翻炒出汁。 

6. 加入适量清水，大火烧开。 

7. 放入豆腐块，煮 3 分钟左右。 

8. 慢慢倒入鸡蛋液，搅拌均匀。 

9. 加入适量盐、生抽调味，淋入少许香油即可。 

**三、营养价值 这道番茄豆腐汤具有以下营养价值：** 

1. 丰富的蛋白质：豆腐和鸡蛋都是优质蛋白质的良好来源，能够为身体提供充足的营养，增强体质。 

2. 多种维生素和矿物质：番茄富含维生素 C、维生素 E、胡萝卜素等营养成分，豆腐富含钙、磷、铁等营养成分，这道汤能够为身体提供多种维生素和矿物质，满足身体的需求。 

3. 抗氧化作用：番茄中的番茄红素具有很强的抗氧化作用，能够清除自由基，预防衰老和疾病。 

4. 促进消化：这道汤口感鲜美，容易消化，能够促进食欲，帮助身体更好地吸收营养。

 

**四、注意事项 **

1. 番茄在烫皮的时候，时间不要过长，以免营养流失。 

2. 豆腐在焯水的时候，可以加入少许盐，这样可以使豆腐更加紧实，不易破碎。 

3.鸡蛋液在倒入的时候，要慢慢倒入，同时用勺子搅拌，这样可以使鸡蛋液更加均匀地分布在汤中。 

4.这道汤的调料要适量，不要过于油腻和辛辣，以免影响口感和消化。
