# 生殖中心供卵贵还是供精贵？费用大概多少？

> 更新时间：2026-09-15 (UTC+8)

自然怀孕顺产过两个孩子，第二个19年4月生的，因病走了，现在想再生，备孕三个月一直没怀，这个月是第三个月做的卵泡监测，还是没怀上。后面检查发现老公有弱精症，我呢有卵巢早衰，做过一次试管失败了，有考虑去申请供精或者供卵试管，想问问在生殖中心供精和供卵的费用大概是多少？哪个更贵一些？

在国内的生殖中心供卵和供精都是无偿的，所以不存在说哪个更贵。但一般在生殖中心申请供卵都是做供卵试管，费用一般在3-10万元不等，而供精除了可以做供精试管外，还可以做供精人授，费用大概在8000~15000元左右，所以具体生殖中心供卵贵还是供精贵需要看之后的需求，每个人的花费都是不相同的。

目前我国是支持部分生殖中心开展供精供卵技术的，供精供卵是不收费的，但是供精供卵之后所做的人工授精或试管婴儿费用是不同的，下面就为大家具体分析生殖中心供卵相关费用和供精相关费用：

- 1. 供卵试管，目前公立医院供卵试管费用在3-10万元不等，因为是供卵所以女性是可以免去促排卵费用的，只需要支付检查、受精、内膜准备、移植等等费用；
- 2. 供精人授，在生殖中心申请供精是免费的，如果是做供精人工授精费用是较便宜的，只包含了检查、促排、精液优化、手术费用，大概在10000元左右；
- 3. 供精试管，相较于人工授精，拿别人精子做试管价格会贵一些，在4-10万元不等，它相较于供卵试管婴儿会多出促排卵费用，所以价格也会相对较贵一些；
- 4. 试管手术费用，供精供卵试管婴儿具体花费哪个更贵需要看试管代数，一代试管费用会较便宜，在3-4万元左右，二代在4-5万元左右，三代最贵在6-10万元左右。
以上就是生殖中心供卵和供精相关技术费用详情，这个价格仅作为一个参考，具体花费与医院等级定价，患者身体素质等等有关系，每个人的费用是不同的，所以并不能得出生殖中心供卵贵还是供精贵。
